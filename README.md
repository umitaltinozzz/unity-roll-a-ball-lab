A Unity Roll-a-Ball style prototype built to practice beginner 3D game development concepts: player movement, camera following, physics, materials, and scene setup.

## What It Does

- Implements ball/player movement logic
- Includes a camera follow script
- Uses Unity materials and scene configuration
- Demonstrates an introductory physics-based Unity gameplay loop

## Tech Stack

- Unity
- C#
- 3D physics
- Unity scenes and materials

## Running Locally

1. Open the repository folder with Unity Hub.
2. Use the Unity version listed in `ProjectSettings/ProjectVersion.txt`.
3. Open the sample scene.
4. Press Play in the Unity Editor.

## Repository Notes

Unity `Library`, temporary files, logs, generated build output, and user-specific settings are excluded.
